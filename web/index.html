提取通行密钥

      
    

    
通行密钥就是 Pixiv 的 refresh_token。推荐用下面的一键登录；也可以手动粘贴授权码，或从本机已保存的工具缓存导入。


    

      
一键登录（推荐）

      
会打开程序内置的 Pixiv 登录窗口。登录完成（含验证码 / 2FA）后会自动抓取授权码并提取通行密钥，不需要按 F12，也不用手动复制。

      

        
        
      

    


    

      
1手动提取（备用）

      
打开授权页登录后，浏览器会尝试跳转 pixiv://。按 F12 打开开发者工具的 Network 面板，找到 callback?…code=… 或 pixiv://… 请求，复制整段 URL 或 code 填到下面。code 约 30 秒内有效。
